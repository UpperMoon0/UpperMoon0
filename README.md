## Selected work

**[Discord Adapter](https://github.com/UpperMoon0/Discord-Adapter)**  
Discord-to-Lily bridge and guild-scoped MCP administration service with OAuth 2.0 + PKCE, Redis-backed policy controls, media inspection, and a large semantic administration surface.

**[NsTut Economy](https://github.com/UpperMoon0/Economy)**  
A multi-version, multi-loader Minecraft economy with an order book, physical item and fluid settlement, automated matching, portfolio tracking, and an in-game market terminal.

**[Simply Screens](https://github.com/UpperMoon0/Simply-Screens)**  
A multi-version Minecraft display system with synchronized screen networks, media upload and download, SSRF hardening, server-side validation, and recovery-safe storage.
